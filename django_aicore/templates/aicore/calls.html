Строка пишется на каждый вызов, включая успешный — иначе доля отказов не считается. Приложение берётся из стека вызова — тем же значением, которое уходит в OpenRouter заголовком X-Title, поэтому наша разбивка сходится с их Activity. Колонка HTTP отделяет отказ провайдера (429 — упёрлись в лимит модели, 401, 5xx) от обрыва тракта, у которого HTTP-кода нет вовсе: причина отказа — в колонке «Исход». Цену называет сам OpenRouter: она приходит в ответе на вызов, а по строкам без цены её добирает кнопка наверху — по id генерации, по одному запросу на строку. {% if stuck %} Ещё у {{ stuck }} чат-вызовов цены не будет никогда: они записаны до того, как слой начал сохранять id генерации, либо шли не через OpenRouter. {% endif %} У эмбеддингов цены нет: они идут своим endpoint-ом мимо OpenRouter.
